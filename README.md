# HRJ SHOOTING

HTML5 캔버스 탄막(단무쿠) 슈팅 게임. 순수 Vanilla JS + WebAudio 합성 효과음, 외부 의존성 0.

## 실행

정적 파일만 있으므로 브라우저에서 바로 열거나 로컬 서버로 서빙:

```bash
python -m http.server 8731 --directory <이 폴더>
# → http://localhost:8731
```

GitHub Pages에 폴더를 그대로 push하면 바로 동작합니다 (상대경로만 사용).

## 조작

| 입력 | 기능 |
|---|---|
| 방향키 / WASD | 이동 |
| (자동) | 자동사격 |
| 스페이스 | 폭탄 — 전 화면 적탄 제거 + 대미지 (3개 보유, 보스전 중에도 사용 가능) |
| P / Esc | 일시정지 |
| M | 사운드 켜기/끄기 |
| 터치 드래그 | 이동 (모바일), 2지점 탭 = 폭탄 |

## 구성

- 5개 스테이지, 각 웨이브(적기체 군) → 보스전. 보스 처치 = 스테이지 클리어.
- ST1 소형기 직선 탄막 → 보스A(좌우 이동 + 3방향 방사)
- ST2 곡선 중형기 + 나선 탄막 → 보스B(8방향 방사 + 직선 연사)
- ST3 분열 대형기 + 빗발 탄막 → 보스C(무적 방패 구간 포함 패턴 전환 2종)
- ST4 고속 기동 소형기, 교차 탄막, 자폭기 → 보스D(탄막 벽 개폐 + 추적탄)
- ST5 모든 패턴 혼합 → 최종보스E(HP 구간별 3단계 전환, 진입 시 대형 탄막)

## 점수

- 격파: 소형 100 / 중형 300 / 대형 800 / 보스 5000 + 스테이지 보너스 (ST1~5: 1000/2000/3000/4000/5000)
- 생존 시간: 1초당 10점
- N스테이지 사망 시 최종 점수 = 클리어한 스테이지 합 + 사망 스테이지 부분 점수 (게임 오버 화면에 내역 표기)
- 5스테이지 전 클리어 시 VICTORY

## 플레이어

- HP 3히트, 피격 시 1.5초 무적(깜빡임). 히트박스는 기체 중앙의 작은 빨간 점.
- 중형/대형 격파 시 낮은 확률로 파워업 드랍: `+` = HP 회복, `B` = 폭탄 +1 (최대 5)

## 파일 구성

```
index.html      페이지 구조 + 화면 오버레이(메뉴/정지/클리어/게임오버/승리)
css/style.css   반응형 스케일(480x640 등비), UI 스타일
js/audio.js     WebAudio 합성 효과음 (발사/폭발/피격/경고/클리어/게임오버/승리, M키 mute)
js/entities.js  객체풀(적탄 900/플레이어탄 120/파티클 600), 플레이어, 적기체, 보스 A~E, 파워업, 스타필드
js/stages.js    5개 스테이지 웨이브 이벤트 + 보스 정의, StageRunner
js/main.js      게임 루프(rAF, dt 기반), 상태머신, 점수, 렌더링, 입력(키보드/터치)
```

## 기술 노트

- 캔버스 480×640 기준, CSS `min(100vw, 100vh·3:4)` 로 등비 스케일.
- `requestAnimationFrame` + dt 기반 이동 (프레임레이트 독립), dt 최대 50ms 클램프.
- 적탄은 고정 크기 객체풀 재사용 → 동시 300+ 탄 유지, 60fps 목표.
- AudioContext는 첫 사용자 제스처(버튼 클릭/키 입력) 시 `resume()`.
- localStorage·CDN·외부 리소스 미사용.
